IT essentials

Information technology (IT) is the use of computers, software and networks to store, process and share information. It includes everyday tasks such as creating documents, communicating online and keeping data organised. Explore IT topics.

Start with computer hardware and software, then explore networks and basic web development. Watch a short tutorial, make notes and practise one task at a time. Start with the video tutorials.

Use a different strong password for each account, enable two-step verification and keep your software updated. Check unexpected messages carefully, avoid unknown downloads and back up important work. Read the online safety guide.

IT glossary

8 useful terms

Showing all 8 terms. Select a term to read its meaning.

CPUCentral processing unit

The processor carries out instructions and calculations. It works with memory and the other components in your computer.

RAMRandom access memory

Temporary working memory for programs and data in use. Its contents are normally lost when the power is switched off.

SSDSolid-state drive

A storage device that keeps files and applications using flash memory. It retains data when the computer is off.

DNSDomain name system

A system that helps translate a website’s domain name into the IP address used to reach it.

HTMLHypertext markup language

The language used to structure web pages with headings, paragraphs, images, links and other elements.

CSSCascading style sheets

The language used to control a web page’s appearance, including colours, fonts, spacing and layout.

Wi-FiWireless networking

A way for devices to connect to a local network using radio waves. Wi-Fi and the internet are different things.

Operating systemSystem software

Software that manages hardware and provides services for applications. Examples include Windows, macOS and Linux.

Everyday IT questions

Start with the hardware video, then read the computer component guide. Pick one unfamiliar term and look it up in the glossary. Open the tutorials.

Check that Wi-Fi is enabled and that you have selected the right network. See whether another device can connect, then try disconnecting and reconnecting your own device. Review networking basics.

Create a folder for each subject and use clear filenames with a date or version. Keep a backup of important work and check that you can open the backup. Explore learning resources.
