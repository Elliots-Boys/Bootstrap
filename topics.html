Computer hardware

Hardware means the physical parts of a computer. The CPU processes instructions, RAM holds data currently in use, and an SSD or hard drive stores files for later. The motherboard connects the components.

Example: when you open a document, the computer loads data from storage into RAM so the processor can work with it.

Software and operating systems

Software is the set of programs and instructions a computer runs. An operating system, such as Windows, macOS or Linux, manages hardware and provides services for applications.

Example: a word processor is application software; the operating system manages saving its files and sending a document to a printer.

Networks and the internet

A network connects devices so they can exchange data. Ethernet uses a cable; Wi-Fi uses radio waves. A router forwards data between networks. The internet connects many networks around the world.

Example: your laptop connects to a router to request a web page from a server. DNS helps translate the site's domain name into an IP address.

Online safety and cybersecurity

Protect your accounts with unique passwords and two-step verification. Install updates, keep backups and check links before opening them. Phishing messages pretend to be trustworthy to trick you into sharing information or downloading harmful files.

Try this: if a message asks you to sign in urgently, open the service's official website yourself instead of following the message's link.

Web development

HTML gives a web page its structure, CSS controls its appearance and JavaScript adds interaction. A responsive layout adapts to different screen sizes so a site works on phones and computers.

Try this: create a page with a heading, a paragraph and a link, then use CSS to change the colours and spacing.
